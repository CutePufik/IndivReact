# Погодный дашборд

Одностраничный сайт на React: поиск города, карта с погодой и график температуры и осадков на 5 дней.

Данные берёт [Open-Meteo](https://open-meteo.com/) без ключа. Карта нарисована своим SVG, контур суши — Natural Earth.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`. Публикация на GitHub Pages идёт из ветки `main`.

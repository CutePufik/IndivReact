# Java и байткод

Одностраничный сайт: слева исходный код Java, справа его байткод. Через 3 секунды после того, как набор текста остановился, страница сама отправляет код в Compiler Explorer.

Используется открытый API без ключа:

`POST https://godbolt.org/api/compiler/java2102/compile`

Компилятор — OpenJDK 21 (`java2102`). В ответе поле `asm` содержит вывод `javap`: инструкции байткода. Сервис отдаёт заголовок `Access-Control-Allow-Origin: *`, поэтому страница на GitHub Pages ходит к нему из браузера.

Файл на стороне сервиса называется `example.java`. Перед запросом у объявления `class`, `interface`, `enum` и `record` снимается модификатор `public`, иначе `javac` требует совпадения имени файла и имени класса. В редакторе текст остаётся как его ввёл пользователь.

```bash
npm install
npm run dev
```
